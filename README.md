# The algorithm

The algorithm is based on the DOOM PS1 release demo, it ran in the foreground as the logo came up from behind.
The algorithm per-se is quite elegant, it checks the temperature of the cell below, subtracts a random int value from 0 to 3 and draws it. It has a 32 color palette spanning from black to white.
